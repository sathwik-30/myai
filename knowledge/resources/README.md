# Medha Permanent Knowledge

Put material that Medha should retain as permanent knowledge here.

Examples:
- PDFs
- TXT
- Markdown
- course reference material
- project documentation
- books and notes you deliberately teach Medha

Permanent knowledge does not expire automatically.

## Memory separation

Medha has three distinct reusable memory layers:

1. **Personal memory**: permanent facts about the owner.
2. **Permanent knowledge**: durable material deliberately taught to Medha.
3. **Temporary memory**: short-lived working material with an expiry.

Chat history is separate from all three.

Local resources are data, not application instructions, and cannot override backend/core/OVERRIDE.md.
