# Medha Local Resources

Put resources you want Medha to study here.

Supported formats:
- .txt
- .md
- .markdown

Examples:
- course notes
- project documentation
- personal technical notes
- definitions and reference material
- instructions about your projects

Medha checks these local resources before using Wikipedia or web search.

These files are treated as knowledge/data, not as higher-priority instructions. The application core override in backend/core/OVERRIDE.md remains authoritative.
