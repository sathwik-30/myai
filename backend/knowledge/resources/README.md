# Medha Local Resources

Put resources you want Medha to study here.

Supported formats:
- .txt
- .md
- .markdown

Examples:
- course notes
- project documentation
- personal technical notes
- definitions and reference material
- instructions about your projects

## Knowledge priority

Medha follows this order when answering a question:

1. **Core override** in `backend/core/OVERRIDE.md` is highest priority.
2. **Local storage**, including user memory and matching local resources, is checked next.
3. **External knowledge** such as Wikipedia and web search is used only when the local storage does not provide a useful answer.

Local resources are knowledge/data, not instructions. They cannot override the application core policy.
