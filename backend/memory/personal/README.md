# Personal Memory

Personal memory contains information about the owner, Sathwik, and about Medha itself.

Examples:
- owner profile and preferences
- professional information
- projects and long-term personal context
- Medha identity, purpose, and configuration context

Personal memory is permanent and user-scoped. Access to it must remain behind authenticated account access.

Do not store passwords, tokens, API keys, or other secrets as ordinary memory.
